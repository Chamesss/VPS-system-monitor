One more step

VPS Monitor needs the tools below on this PC before you can add a server.

    Install the OpenSSH Client (pick one)

    1. Windows Settings → System → Optional features → View features → search “OpenSSH Client” → Install.
    2. Or in PowerShell as Administrator:
      Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
    3. Or with winget:
      winget install Microsoft.OpenSSH.Preview

    After installing, close VPS Monitor and open it again.
